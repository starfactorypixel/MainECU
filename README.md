## Важное
Эта версия прошивки предназначена для работы с платами версии 2.2. Если у вас более ранние модификации железа, то ищите прошивку в соответствующих ветках.

## Локальные настройки

Проект для Visual Studio Code + PlatformIO.

Настройки, зависящие от конкретной машины, хранятся в файле `platformio_local.ini` в корне проекта. Файл не хранится в репозитории, создайте его сами:

```ini
[env]
monitor_port = COM4
upload_port = COM4

[local]
build_flags = 
;	-D USE_EMULATOR
;	-D NO_CAN_SEND
```

Если файла нет, проект соберётся с настройками по умолчанию, а порт PlatformIO попытается определить автоматически.

## Сборка в Windows

В Windows возможны непредсказуемые ошибки сборки, обычно вида `file not found`. Как правило, причина в длинном пути к профилю пользователя или кириллице и пробелах в нём.

Решение: перенести папку PlatformIO на короткий путь. Выполните в `cmd` после установки PlatformIO:

```cmd
mklink /J C:\pio %USERPROFILE%\.platformio
setx PLATFORMIO_CORE_DIR C:\pio
```

Первая команда создаёт ссылку `C:\pio` на папку с тулчейнами PlatformIO. Вторая указывает PlatformIO работать через этот путь.

После этого перезапустите VS Code, чтобы он увидел новую переменную окружения.
